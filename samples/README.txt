HoloStudio3D sample files
=========================

Try these in Hologram mode (click a drop box and this folder opens first):

  sample-knot-picture.png + sample-knot-depth.png
      Picture + depth: a torus knot and its depth map (white = near).
  sample-torus-knot.obj
      3D model: the same knot. Try 2 views, 3D strength 6-10 degrees, tilt about 25 degrees.
  sample-cube.stl
      3D model: a plain cube. Turn it (e.g. 30 degrees left, 25 up) so you see three faces.
  hologram-test-model.obj
      3D model: a ring with a cube in front and behind, for checking depth direction.
  stereo-test-picture.png + stereo-test-depth.png, stereo-test-sbs.png
      Simple test shapes: picture + depth, and a side-by-side pair.

For the Magic Eye-style picture page:

  torus-depth.png
      A depth map to try as the source; torus.png is what the finished picture looks like.

Rainbow test disc:

  diffraction-test-map.png, diffraction-test-key.txt
      What the rainbow test disc layout and its key look like.
