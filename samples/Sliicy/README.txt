Extra samples by Sliicy (github.com/Sliicy)
===========================================

Real test results shared by Sliicy, made with HoloStudio3D on Verbatim DVD-R discs.
Each "-key.txt" is the key file the app wrote for that disc, with the settings used.

Hologram mode:
  hologram-test-patches-*             the test-patch disc

Magic Eye-style picture:
  Inner-3d.png, Inner-3d-depth.png             a star stereogram and its depth map
  Inner-3d_0.06.png, Inner-3d_0.06-depth.png   the same with finer (0.06 mm) dots

Rainbow test disc:
  diffraction-test-map.png, diffraction-test-key.txt

Thank you, Sliicy!
